# Lists

Tight list:

- one
- two
- three

Loose list:

- one

- two

- three

Nesting by depth (disc, ring, square):

- level 1
  - level 2
    - level 3
      - level 4

Ordered with a start number:

7. seven
8. eight
9. nine
10. ten

Mixed:

1. first
   - bullet inside
   - another
2. second

   A paragraph in an item.

Task list:

- [ ] open task
- [x] done task

Definition list:

Term
: Definition text that is indented.

Another term
: First definition
: Second definition
