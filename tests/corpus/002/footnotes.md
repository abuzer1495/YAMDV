# Footnotes

GitHub numbers notes by first reference: this cites the second definition first[^later],
then the first one[^early], and the first again[^later].

[^early]: Defined first in the source, numbered second.

A paragraph between the definitions keeps its place.

[^later]: Defined last, referenced first, so it is note 1 with two back-links.

The notes section is rendered after this paragraph.
