# YAMDV keyboard shortcuts

| Action | Keys |
|---|---|
| Open file | `Ctrl+O` |
| Reload | `F5` |
| Close window | `Esc`, `Ctrl+W` |
| Find | `Ctrl+F`; next / previous: `Enter` / `Shift+Enter`, `Ctrl+G` / `Ctrl+Shift+G` |
| Copy / Copy as Markdown | `Ctrl+C` / `Ctrl+Shift+C` |
| Select all | `Ctrl+A` |
| Context menu | right-click, `Shift+F10`, Menu key |
| Show outline | `Ctrl+\` |
| Add to / remove from favorites | `Ctrl+D` |
| Open in external editor | `F4`, `Ctrl+E` |
| Font size | `Ctrl+wheel`, `Ctrl+=` / `Ctrl+-` / `Ctrl+0`, `Ctrl+↑` / `Ctrl+↓` |
| Column width | `Alt+wheel`, `Alt+↑` / `Alt+↓`, `Alt+0` |
| Back / forward | `Alt+←` / `Alt+→`, mouse buttons 4 / 5 |
| Next / previous link | `Tab` / `Shift+Tab`, `Enter` opens |
| Open link in a new window | `Ctrl+click`, middle-click |
| Scroll | arrows, `Page Up` / `Page Down`, `Space`, `Home` / `End` |
| This help | `F1` |

Settings live in the context menu (**Settings ▸ Edit settings file** opens `settings.ini`).
