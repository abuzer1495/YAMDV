# YAMDV klavye kısayolları

| İşlem | Tuşlar |
|---|---|
| Dosya aç | `Ctrl+O` |
| Yeniden yükle | `F5` |
| Pencereyi kapat | `Esc`, `Ctrl+W` |
| Bul | `Ctrl+F`; sonraki / önceki: `Enter` / `Shift+Enter`, `Ctrl+G` / `Ctrl+Shift+G` |
| Kopyala / Markdown olarak kopyala | `Ctrl+C` / `Ctrl+Shift+C` |
| Tümünü seç | `Ctrl+A` |
| Bağlam menüsü | sağ tık, `Shift+F10`, Menü tuşu |
| Ana hattı göster | `Ctrl+\` |
| Sık kullanılanlara ekle / çıkar | `Ctrl+D` |
| Harici düzenleyicide aç | `F4`, `Ctrl+E` |
| PDF olarak dışa aktar… / Yazdır… | `Ctrl+Shift+E` / `Ctrl+P` (HTML: bağlam menüsü ▸ Dışa aktar) |
| Yazı boyutu | `Ctrl+tekerlek`, `Ctrl+=` / `Ctrl+-` / `Ctrl+0`, `Ctrl+↑` / `Ctrl+↓` |
| Sütun genişliği | `Alt+tekerlek`, `Alt+↑` / `Alt+↓`, `Alt+0` |
| Geri / ileri | `Alt+←` / `Alt+→`, fare düğmeleri 4 / 5 |
| Sonraki / önceki bağlantı | `Tab` / `Shift+Tab`, `Enter` açar |
| Bağlantıyı yeni pencerede aç | `Ctrl+tık`, orta tık |
| Kaydır | oklar, `Page Up` / `Page Down`, `Boşluk`, `Home` / `End` |
| Bu yardım | `F1` |

Ayarlar bağlam menüsündedir (**Ayarlar ▸ Ayar dosyasını düzenle** `settings.ini` dosyasını açar).
