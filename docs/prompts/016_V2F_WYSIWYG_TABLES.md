## 2. Setup
1. **ADR-0020 "F2 reveal model"** (write it before any F2 code, ≤ 1 page). It decides:
   - **source map:** the mapping between rendered text positions and rope byte offsets, per paragraph, built from the parser events;
   - **reveal set:** the constructs whose markers are visible for a given caret or selection;
   - **caret movement:** hidden markers are skipped, and revealed markers can be entered;
   - **relayout scope:** a reveal change re-lays out at most the 2 affected paragraphs; an edit uses the ADR-0007 splice of the touched block only;
   - **undo grouping;**
   - **block-level reveal:** which constructs keep the v1 behavior (code, math, Mermaid, HTML, front matter).

### Part 1 — F2 becomes full WYSIWYG (R-F2-02, R-F2-03; FUT-43)
1. **Inline reveal** (R-F2-02, B.13.2)
   - **Behavior:** the page stays rendered with the same typography. A marker is visible in `marker` color, at the surrounding text size, only while the caret is inside or adjacent to its span.
   - **Inline markers:** `**`, `*`, `~~`, `==`, `` ` ``, `[`…`](url)` and `$`.
   - **Line markers:** `## `, `> `, `- `, `1. `, `- [ ] ` and callout heads show while the caret is on that line.
   - **Selections:** the reveal set covers both selection ends.
   - **Escapes and entities:** they map correctly, and the caret never lands inside a hidden marker.
   - **Clusters:** CJK and emoji clusters stay whole.
2. **Block constructs** (R-F2-02 sub-items, P-47)
   - **Code blocks:**
     - The fence lines show while the caret is in the block.
     - The code is edited as monospace text with live highlighting.
     - The language label is an input with autocomplete of the known languages (R-F2-09, the language-picker popover of B.10.6).
   - **Math:** with the caret inside `$…$` / `$$…$$`, the source shows, with a live-rendered preview popover below it.
   - **Mermaid:** with the caret inside the block, the source shows, with the live diagram below it. Re-layout is debounced by 150 ms, and the last good diagram stays while the source has an error.
   - **Images:** with the caret on the image line, `![alt](src)` shows above the image, which stays visible.
   - **HTML blocks, front matter and footnote definitions:** source in place (P-47).
3. **Typing transforms** (R-F2-03)
   - **Line starts:** `# `…`###### `, `- ` / `* ` / `+ `, `1. `, `[ ] ` / `[x] ` inside a list, and `> `.
   - **Blocks on `Enter`:**
     - ```` ``` ```` / ```` ```lang ```` + `Enter` gives a code block with the caret inside and no stray blank line;
     - `---` + `Enter` gives a rule;
     - `$$` + `Enter` gives a math block;
     - a pipe header row + `Enter` gives a table with its delimiter row.
   - **Undo:** each transform is one undo step, and `Ctrl+Z` right after it gives back the literal text.
4. **Links** (R-F2-08)
   - **Click:** a click places the caret, and `Ctrl+click` follows the link (R-LINK).
   - **Link editor:** `Ctrl+K` opens the link-editor popover (B.10.6) with text, URL and title fields, built on the V2-B input and the V2-C popover.
5. **Cross-block selection** (R-F2-06)
   - **One step:** copy, cut and delete work across paragraphs, lists, tables and code as one undo step.
   - **Clipboard:** it gets Markdown, HTML (through the export writer, with no script) and plain text.
   - **Pasting** multi-block Markdown creates the blocks.
6. **Smaller items**
   - **Checkboxes:** clicking one in F2 toggles `[ ]` ↔ `[x]` (R-F2-07).
   - **Context menu:** it has **Format ▸**, **Insert ▸** (Table…, Code block, Callout ▸ 5 types, Math block, Mermaid diagram, Horizontal rule, Image…, Link…, Footnote) and **Table ▸** inside a table (R-F2-05). Add whatever is missing.
7. **Data safety** (R-F2-10, S-FILE-10)
   - **Untouched blocks:** blocks the user did not touch are never re-serialized. Saving after edits in one block changes only that block's bytes.
   - **Encoding:** line endings and the BOM stay as they were.

### Part 2 — Table editing (R-TBL-01…08; FUT-44)
8. **Cell editing** (R-TBL-01, R-TBL-04)
   - **In-cell editing:** cells use the inline reveal from item 1; a table is never shown as pipes.
   - **Keys:**
     - `Tab` / `Shift+Tab` move to the next / previous cell, and `Tab` in the last cell adds a row;
     - `Enter` moves to the cell below, adding a row at the end;
     - `Shift+Enter` inserts `<br>`.
   - **Empty cells** keep the row height, so the caret can be placed in them.
   - **Pipes:** `\|` is escaped and unescaped both ways.
9. **Table toolbar** (R-TBL-02, B.6.8)
   - **Where:** in F2, the hover pill gets the editing tools.
   - **Tools:**
     - add a row above / below
     - add a column left / right
     - delete a row / column
     - align a column (left / center / right / none)
     - sort a column ascending / descending (natural and locale-aware with Turkish collation; one undo step)
     - move a row up / down and a column left / right
     - delete the table
     - ⛶ and CSV
   - **Keys:** `Ctrl+Alt+↑/↓` / `←/→` and `Ctrl+Shift+Backspace` (SHORTCUTS).
10. **Drag handles** (R-TBL-03)
    - **Grips:** a column grip on header hover and a row grip at the left edge, 12 × 20 with ⋮⋮ dots in `text_muted`.
    - **Feedback:** a live 2 px `accent` drop indicator.
    - **Undo:** a move is one undo step.
11. **Re-serialization** (R-TBL-05, R-TBL-08)
    - **Pretty-align:** an edited table is re-serialized with its columns aligned (`editing.auto_format_tables`), with East-Asian-width-aware padding. Other tables stay byte-identical.
    - **Adjacency:** inserting a table next to another table keeps a blank line between them, so they never merge.
12. **Insert-table picker** (R-TBL-06)
    - A 10 × 10 grid popover with a live "R × C" label.
    - It opens from `Ctrl+T` and from Insert ▸ Table…; `Ctrl+T` no longer inserts the fixed 2 × 2 snippet.
    - It works with the arrow keys and `Enter`.
13. **TSV / CSV paste** (R-TBL-07)
    - **Inside a table:** TSV or CSV (from Excel, RFC 4180 quoting) expands into the cells, adding rows and columns as needed.
    - **Outside a table:** pasting TSV offers "Convert to table" as a banner-style inline prompt with [Convert] [Keep as text].
