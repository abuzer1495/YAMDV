# YAMDV — Yet Another Markdown Viewer

A native Windows Markdown viewer and WYSIWYG editor written from scratch in Rust.
Reading-first, fully offline, tiny (target: 3–5 MB private working set).

**Status:** Phase V1-A (app shell & daily use) of the v1 plan — a read-only Markdown viewer; editing, math/Mermaid and export follow in V1-B…V1-D.
